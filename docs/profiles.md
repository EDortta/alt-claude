# Model profiles

Profiles are declarative files under `profiles/`. The preferred invocation is:

```bash
alt-claude --profile north-mini-code --yolo
```

Compatibility commands such as `alt-claude-north-mini-code` are generated by the installer and delegate to the same path.

Each profile defines provider/model metadata plus a context policy:

```bash
PROVIDER=openrouter
MODEL=vendor/model:free
DISPLAY_NAME="Readable name"
STATUS=experimental
CONTEXT_WINDOW=262144
SAFE_CONTEXT_TOKENS=185000
AUTO_COMPACT_PCT=65
NOTES="Operational note"
```

`SAFE_CONTEXT_TOKENS` reserves room for tool input and model output. When `--resume` points to a local session already above that threshold, alt-claude refuses the likely-to-fail request and recommends `alt-claude compact SESSION_ID`.

`AUTO_COMPACT_PCT` is also exported as Claude Code's early auto-compaction hint, but the offline guard is kept because auto-compaction behavior can change between Claude Code versions.

## Current profiles

Active:

- `north-mini-code` — Cohere North Mini Code; 256K declared window, 180K safe resume threshold.
- `laguna` — Poolside Laguna S 2.1; 262K / 185K.
- `nemotron` — NVIDIA Nemotron 3 Ultra; 1M / 780K.

Experimental:

- `laguna-xs` — 262K / 185K.
- `nemotron-lightning` — 1M / 780K.
- `nex-pro` — 262K / 185K.
- `nex-mini` — 262K / 185K.
- `inkling-small` — ~1M / 800K.
- `inkling` — ~1M / 800K.
- `deepseek-v4-flash` — ~1M / 800K.
- `glm-5.3-flash` — ~1M / 800K.
- `free` — conservative 262K / 170K because the actual routed model varies.

Experimental means wired and catalog-validated, not yet promoted by repeated real repository work.

The free Inkling endpoints can have research/model-improvement data-retention terms. Do not use them with private source code until those terms are acceptable.

## Validation

```bash
bash tools/check-profiles.sh
```

The validator checks current OpenRouter existence, zero-price status, API context length, declared context and the safe threshold. Context drift or an unsafe threshold fails the command.

## Adding a profile

Add one `.env` file under `profiles/`, including the three context fields above, and rerun `./install.sh`. Do not add a separate parser or copied launcher.

Free endpoints can disappear, change limits, become rate-limited or change data-retention terms. Treat the catalog as operational configuration, not a permanent guarantee.
