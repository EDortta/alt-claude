PERGUNTAS PERFEITAMENTE RAZOÁVEIS

Antes que você
abra outra aba.

Isso substitui o Claude Code?

Não. Ele preserva a interface que você já usa e organiza caminhos compatíveis por baixo dela. É menos uma mudança de casa e mais uma porta nos fundos.

Preciso aprender outro fluxo?

Só uma ideia nova: alt-claude --use rota. Seus outros argumentos continuam seguindo viagem.

Minhas credenciais ficam onde?

Fora do repositório, em arquivos locais com permissões restritas. O README mostra a estrutura recomendada sem pedir que você cole segredo em lugar divertido.

É para momentos específicos?

É para qualquer momento em que ter escolha pareça mais inteligente do que não ter. Curiosamente, são muitos.
